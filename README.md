# Города — Telegram Mini App и бот

Игра в города с атласом, фотографиями, картой и личными достижениями.

## Возможности

- Четыре режима: весь мир, Россия, 60 секунд на ход, ежедневная цепочка из 10 ходов.
- Проверка названия, последней буквы, повторов и альтернативных имён.
- 15 289 городов для ввода, 184 известных города с русскими названиями для ответов бота и атласа.
- Карточки обоих городов: страна, население, фото Wikimedia, ссылка на Википедию, карта OpenStreetMap.
- Три подсказки за игру, очки, журнал маршрута, избранное, достижения и история последних 20 игр.
- Автоматическое восстановление незаконченной игры; таймер учитывает время вне приложения.
- Светлая и тёмная темы Telegram, безопасные отступы, виброотклик и кнопка «Назад».
- Обычный браузерный режим, адаптация под телефон и компьютер.
- Текстовая игра в чате, `/app` и кнопка меню для открытия Mini App.

## Единый файл бота

`CitiesBot_AllInOne.py` содержит код бота, Mini App и сжатый справочник городов. Файлы `bot.py`, `game.py`, `wiki.py` и папка `web` не нужны для запуска этого файла. Библиотеки Python устанавливаются отдельно:

```powershell
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

В `.env` укажи:

```dotenv
TELEGRAM_BOT_TOKEN=токен_от_BotFather
MINI_APP_URL=https://krivonosarseniy11-source.github.io/sitiesgame777/
```

Создай бота через [@BotFather](https://t.me/BotFather) командой `/newbot`. Затем:

```powershell
python CitiesBot_AllInOne.py
```

Бот установит кнопку меню «Играть». Отправь `/start` или `/app` в личный чат с ботом. Чтобы добавить главный Mini App в профиль бота, настрой его в BotFather: `/mybots` → свой бот → Bot Settings → Configure Mini App, указав ту же HTTPS-ссылку.

Python 3.10+. Токены не входят в проект. При работе только с одним файлом установи библиотеки командой:

```powershell
python -m pip install "python-telegram-bot>=22,<23" "geonamescache==3.0.2" "Babel>=2.17,<3" "python-dotenv>=1,<2" "httpx>=0.27,<0.29"
```

## Просмотр без токена

```powershell
python CitiesBot_AllInOne.py --serve
```

Открой `http://127.0.0.1:8080`. Для другого порта: `--port 8090`. Можно выгрузить только Mini App:

```powershell
python CitiesBot_AllInOne.py --export-web docs
```

Папка `docs` содержит готовую статическую сборку. Сборщик JavaScript и npm-зависимости не нужны. Mini App требует HTTPS внутри Telegram; локальный HTTP используется для предпросмотра в браузере.

## GitHub Pages

В Settings → Pages выбери Deploy from a branch, ветку `main`, папку `/docs`, нажми Save. После публикации приложение открывается по адресу:

https://krivonosarseniy11-source.github.io/sitiesgame777/

GitHub Pages размещает Mini App. Сам Python-бот запускается отдельно на постоянно включённом компьютере или сервере. Не добавляй токен в HTML, JavaScript или репозиторий.

## Разработка и проверки

```powershell
python build_single_file.py
python -m unittest -v
node --test web/engine.test.cjs
python -m py_compile CitiesBot_AllInOne.py
```

Сборка обновляет `docs/` и `CitiesBot_AllInOne.py`. После правок в `web` или Python-коде пересобери проект. Тесты покрывают цепочки ходов, неверный ввод, повторы, российский режим, завершение задания дня, справочник, обработку сетевой ошибки и недоступного фото.

## Данные, приватность и границы

Рекорды хранятся в localStorage на устройстве. Telegram ID используется только как локальный ключ профиля, данные авторизации не отправляются на сервер. Общего рейтинга, денежных призов и серверных аккаунтов нет. Результаты можно изменить в браузере, поэтому они подходят для личной игры. Для серверного рейтинга обязательно нужно проверять Telegram `initData` по [официальной инструкции](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app) и рассчитывать ходы на сервере. Сохранения разных устройств и текстового чата не синхронизируются. Текстовые партии в боте хранятся в памяти и сбрасываются после перезапуска процесса.

Источники: [GeoNames](https://www.geonames.org/) через [geonamescache](https://github.com/yaph/geonamescache), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Порог исходной базы — 15 000 жителей, берутся записи с кириллическими названиями. Население — оценка из справочника без указанной даты; оно может быть устаревшим. При совпадении названий выбирается крупнейший город. Некоторые альтернативные имена исторические или относятся к другому языку. Ответы бота ограничены отдельным списком русских имён; победа означает исчерпание этого списка.

Фото: [Wikimedia / PageImages](https://www.mediawiki.org/wiki/Extension:PageImages#API), у каждого изображения своя лицензия и автор на странице файла. Статья сверяется с координатами города (радиус 30 км), сначала русская, затем английская. При отсутствии подтверждённой статьи открывается поиск Википедии. Фото и карты требуют интернета; при их недоступности правила игры продолжают работать после загрузки справочника. Карта: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright). Декоративная схема мира на главном экране не является географической картой. Шрифт Golos Text загружается из Google Fonts, при недоступности используется системный sans-serif.

Навыки, использованные при разработке: Telegram Mini Apps, frontend-design и karpathy-guidelines.
