# Города: Mini App, версия 2

Применены навыки Telegram Mini App и UI/UX Pro Max. Проект — HTML/CSS/JavaScript без фреймворка.

Поиск UI/UX Pro Max `geography game mobile playful` дал общий шаблон лендинга, недостаточно подходящий для игрового экрана. Повторный запрос `gaming entertainment mobile` дал игровую палитру и Russo One. Использованы игровая фиолетовая палитра и акцентная типографика; тяжёлые 3D-эффекты заменены лёгким SVG-глобусом ради производительности Telegram WebView. Структура — рабочий экран игры, а не маркетинговый лендинг.

Токены светлой темы: фон #F6F5FB, текст #27243C, вторичный текст #69667D, поверхности #FFFFFF, акцент #6C45D7, текст кнопок #FFFFFF. Тёмная тема: фон #14131E, поверхности #201E30, текст #F0EDF9, вторичный #AAA6BD, акцент #B7A0FF, текст кнопок #21133E. В Telegram приоритет у соответствующих `--tg-theme-*` переменных. Golos Text для русского интерфейса, Russo One только для буквы хода.

Основной сценарий: режим → буква → поле города → подтверждение → ответ и карточки. Режимы выбираются в отдельном диалоге 2×2 без горизонтальной прокрутки. Навигация фиксирована снизу: Игра, Атлас, Паспорт. На телефоне диалоги открываются снизу, на компьютере — по центру. Карта и подробности не перекрывают основной сценарий.

UI/UX Pro Max `mobile form visible label`: у обоих полей видимая подпись; ошибка связана с полем через `aria-describedby`, `aria-invalid` и live region. SVG-иконки единообразны, декоративные скрыты от скринридера. У активной навигации `aria-current`, у фильтра/избранного/режима — `aria-pressed`. Восстановление фокуса после диалога, видимые focus rings, тач-цели 44–56 px, поддержка reduced motion. Отступы Telegram учитываются для шапки и нижней панели. Данные сохранений и игровые правила сохранены.
